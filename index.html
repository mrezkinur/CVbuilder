Tips Penggunaan CV Builder Pro
Kamu di Laptop / Desktop
Pengalaman terbaik! Isi data CV kamu, lalu langsung Print atau Unduh PDF dengan klik tombol di pojok kanan atas.
Gunakan Export JSON di sidebar untuk backup data CV kamu kapan saja.
Kamu di Perangkat Mobile
Untuk hasil terbaik, Print & Download PDF lebih baik dilakukan di laptop/desktop karena tampilan lebih optimal.
Rekomendasi workflow mobile:
Isi semua data CV di sini klik Export JSON untuk simpan buka di laptop Import JSON Print / Unduh PDF.
Tombol Export JSON ada di menu sidebar (ikon kiri atas). File JSON bisa disimpan ke Google Drive atau kirim ke diri sendiri via WhatsApp.
